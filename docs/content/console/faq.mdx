Common questions about Walrus Console. For the concepts behind the answers, read [What is Walrus Console?](./overview), and for a hands-on walkthrough, follow the [Quick Start](./quickstart).

## Getting started

What Console is, how you get in, and what the storage limits are.

### What is Walrus Console?

A place to store files on Walrus and manage them from a browser or from code. You sign in with a Google or Apple account, mint an API key, and upload. Walrus Console handles the parts you would otherwise do by hand: account and wallet provisioning, storage payment, and metadata.

### How do you sign in?

With a Google account or an Apple account. Walrus Console uses Sui [zkLogin](https://docs.sui.io/concepts/cryptography/zklogin) to derive a Sui address from your identity and provisions a wallet for you, so you never handle private keys to get started. Identities from different providers map to separate accounts. See [Authentication and Accounts](./auth).

### What are the storage limits?

Each space holds up to 5 GB of storage and five folders, and each upload is capped at 100 MiB. See [Storage limits](./overview#storage-limits).

### What happens when you hit a limit?

Uploads stop at the storage cap, and a sixth folder returns a `plan_limit_exceeded` error. Delete files or folders to free space.

### Can you delete your account?

Yes, from **Settings**, under **Account Deletion**: choose **Delete account**, type `DELETE`, then confirm. Deletion removes your folders, files, and API keys permanently and cannot be undone. Memories in Walrus Memory are not affected. See [Delete your account](./overview#delete-your-account).

## Your files

How long files last, how large they get, and which ones Console shows you.

### Do your files expire?

Not on their own. Walrus Console extends the storage of files you upload through Console before it runs out, so you keep your data without a manual renewal step. Files you put on Walrus outside Console, through the CLI or an SDK, need manual renewal. See [Storage epochs](./storage-epochs).

### What is the largest file you can upload?

The per-upload cap is 100 MiB. An upload above the cap fails with a `payload_too_large` error. See [Errors](./api-reference#errors).

### Can Walrus Console see files you already uploaded with the Walrus CLI or SDK?

No. Walrus Console shows only the files you upload through Console, the API, or the MCP server. Files you stored on Walrus directly with the CLI or an SDK are not listed.

### Can you delete a file?

You can delete any file you uploaded through Walrus Console, from the web app or through the [API](./api-reference#delete-a-file). Files you stored outside Console do not appear in Console, so delete those with the Walrus CLI or SDK.

## Building on Console

Programmatic access, agent clients, and what a team shares today.

### What is the API key for?

Everything programmatic. Both the MCP server and any application you write against the API authenticate with it. You mint keys under **Integrations** in Walrus Console, choose a `read_write` or `read_only` role for each, and revoke a key whenever you want. Pick a plain **API key** for the MCP server and for your own applications; a **Management API key** mints further keys programmatically but cannot upload, download, or manage assets. Console shows the full key once, at creation, so store it like a cloud secret access key. You can also rotate a key from Integrations. See [API keys and roles](./overview#api-keys-and-roles).

### What happens when you rotate an API key?

Walrus Console revokes the old key first, then mints a replacement with the same role and name and a new service private key, and shows the new secrets once. There is no overlap: anything using the old key stops working when you rotate and works again once you paste in the new secrets, for example by running the MCP installer's `config` command. Rotate and Revoke are separate actions.

### How do you use Walrus Console with Claude Code or Cursor?

Through the Walrus Console MCP server, the npm package `@mysten-incubation/walrus-console-mcp`, which publishes with Console. It exposes file and folder operations as tools your agent calls. Run `npx -y @mysten-incubation/walrus-console-mcp install` and give it the two values Console showed you when you minted the key: the `hbr_` API key and the `suiprivkey1` service private key. The installer stores them outside your client configuration, so no key goes in the MCP config file. See [Connect AI clients with the MCP server](./mcp-server). After you create a key, the Integrations screen walks you through connecting Claude Desktop, Cursor, or a terminal agent such as Claude Code, Codex, or Gemini CLI. See [Connect from the Console web app](./mcp-server#connect-from-the-walrus-console-web-app).

### Can your team share one account?

An account belongs to one person.

### What is Walrus Memory, and is it in Walrus Console?

Walrus Memory is a separate Walrus product: a portable memory layer for AI agents. Connect your Walrus Memory account from the **Memory** tab to view your memories and delegate keys in Walrus Console. Managing memories and delegate keys happens on the Walrus Memory dashboard. See [Walrus Memory in Console](./overview#walrus-memory-in-console).

### Does Walrus Console work on mobile?

Walrus Console supports desktop browsers.
