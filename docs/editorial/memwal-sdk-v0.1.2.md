**August 14, 2026**

Deterministic offline mock clients make tests credential-free, and idempotency keys collapse
retried writes onto a single paid remember job. Foreign manual-recall blobs are isolated, large
encrypted payloads encode safely, and Zod 3 and 4 peer versions are now both supported.
