**Mainnet** | January 14, 2026

The redundant-upload problem from v2.0.0 is fixed: unchanged files are no longer re-uploaded into
new quilts, only new and modified ones. Blob extension now uses the correct Walrus package ID from
the staking object, error output includes the config path, and the portal dropped its Amplitude
integration.
