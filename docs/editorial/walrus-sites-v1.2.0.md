**Mainnet** | September 22, 2025

More experimental quilt work: `update-quilts` re-creates all resources, and quilt patch IDs
surface in publish and update output and in the sitemap. Header and ignore-file matching in
`ws-resources.json` now uses glob patterns instead of regular expressions, and the GitHub deploy
action accepts exported wallet keys.
